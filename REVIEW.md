# REVIEW

All reviews must be adversarial.

Your review must always provide the following information about yourself:

- Model and Version
- Context Window
- Level of Effort

The same information must be provided about other agents with whom you have
consulted.

## Model

Selectively consult the most capable available model, or if no more capable
model is available, an adversarial sub-agent.

## Documentation Links

Where applicable, link to relevant documentation in GitHub Pages, using the
base URL `https://enorganic.github.io/decorative-secrets/`.

## Body Comment

The body of a review should contain only a brief greeting followed by
any requested changes which could not be pinned to a line in the pull request
diff, then instruction to "see my inline comments" (if there are any).

## Inline Comments

-   Place a comment on each set of sequential lines which require attention, do
    not consolidate similar issues into a single comment
-   Lead with the change(s) being requested. Explanatory details are secondary,
    and should be minimal (or omitted entirely if the ask is self-explanatory).
-   Use courtesies such as "please" where appropriate, but do not introduce
    conciliatory language or provide justification for the ask beyond what is
    needed to make the requested change clear
-   Be concise, but use full (grammatically correct) sentences
-   Do not narrate your process

## Re-Reviews

For a re-review, start at the commit of the reviewer's last complete review
of the affected bundle or library. Do not limit the baseline to the current
pull request's diff against its base branch, as interim reviewers may have
applied different emphasis or a lesser level of scrutiny.
